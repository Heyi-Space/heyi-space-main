## 当前一句话定位

合一空间是一个以宋式美学、极简留白和东方器物为主要空间语言的东方美疗第三空间。它为人们提供家庭与工作之外可以停留、放松、被看见和重新连接自己的地方，并通过音乐、茶、香、身体放松、生命陪伴及疗愈师服务，让内在成长转化为真实可体验的生活方式。

## 当前阶段主线

**生命故事与使命表达＋音乐影像/IP呈现＋真实场域验证＋AI工作方式。**

当前以真实人物、真实故事和真实合作为入口，一边验证音乐影像与生命IP，一边设计“东方美疗第三空间”的最小可行模型，包括空间氛围、单次体验、指定疗愈师、公共活动和会员陪伴。素食馆及其他合作场域继续作为实修和运营验证场，而不是未来空间形态本身。

## 仓库使用原则

- 总仓库存放长期有效的定位、战略、组织和总进度。
- 每个具体项目后续建立独立项目目录或独立仓库。
- 原语音直播已经取消，`heyi-voice` 作为历史资料与复盘仓库保留；原有社群继续用于承接和陪伴星种。
- 音乐体系的歌曲、歌词和音乐使用资料统一维护在 [`Heyi-Space/heyi-music`](https://github.com/Heyi-Space/heyi-music)。
- 已确认的事实直接写入；尚未确认的安排标注“待确认”或“动态调整”。
- 每次更新说明日期、修改内容和下一步行动。
- 重要决策不能只停留在聊天记录中，应沉淀到对应文件。
